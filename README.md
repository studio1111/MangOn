# MangOn — افزونه‌های فارسی Mihon

MangOn پروژه‌ای جامعه‌محور برای فراهم‌کردن افزونه‌های فارسیِ سازگار با **Mihon** است. هدف، ارائهٔ منابع قابل‌دسترسی، جست‌وجو، اطلاعات اثر، فصل‌ها و صفحات خواندن در قالب استاندارد افزونه‌های اندروید است.

> **وضعیت فعلی: پایه‌گذاری و ارزیابی منابع — هنوز هیچ APK یا افزونهٔ قابل نصب منتشر نشده است.** هر منبع فقط پس از پیاده‌سازی، ساخت موفق و آزمایش واقعی در Mihon به‌عنوان «پشتیبانی‌شده» معرفی خواهد شد.

## نصب

در حال حاضر نسخهٔ قابل نصب یا نشانی مخزن افزونه برای افزودن به Mihon منتشر نشده است. پس از نخستین انتشار پایدار، این بخش با نشانی دقیق مخزن و راهنمای نصب به‌روزرسانی می‌شود.

## منابع بررسی‌شده

| منبع | وضعیت بررسی اولیه | نکتهٔ فنی |
| --- | --- | --- |
| Mangate | نیازمند بررسی بیشتر | فهرست و جزئیات عمومی قابل مشاهده‌اند؛ بسیاری از فصل‌ها اشتراکی‌اند و خود سایت محدودیت دسترسی خارج از ایران را اعلام می‌کند. |
| ManEast | نیازمند بررسی بیشتر | صفحات فهرست و جزئیات عمومی‌اند؛ دسترسی واقعی به فصل و تصاویر هنوز تأیید نشده است. |
| MangaUp | نیازمند بررسی بیشتر | صفحات فهرست و جزئیات عمومی‌اند؛ مسیر فصل/صفحات هنوز بررسی کامل نشده است. |
| ManhwaChi | نامزد اول برای نمونه‌سازی | جزئیات اثر و پیوند فصل‌ها قابل مشاهده‌اند؛ برخی فصل‌ها اشتراکی‌اند. فقط فصل‌های عمومی و مجاز قابل پشتیبانی‌اند. |
| Mangato | فعلاً مناسب خواندن آنلاین نیست | صفحهٔ نمونه اعلام می‌کند اثر فقط دانلودی است؛ این با مدل استاندارد صفحه‌خوان Mihon یکسان نیست. |
| DomComic | خارج از دامنه | فروشگاه چاپی است، نه منبع عمومی خواندن آنلاین. |

## اصول پروژه

- پیروی از قراردادها و API جاری Keiyoushi؛ برای منبع جدید از KeiSource و @Source استفاده می‌شود، نه الگوهای قدیمی HttpSource.
- هر منبع یک ماژول مستقل و نسخه‌گذاری‌شده دارد.
- فقط محتوای عمومی و مجاز؛ بدون دورزدن ورود، اشتراک، پرداخت، محدودیت جغرافیایی یا سازوکارهای حفاظتی.
- مدیریت خطا، صفحه‌بندی، URLهای نسبی، ترتیب صفحات، هدرهای لازم و محدودیت نرخ درخواست.
- هیچ منبعی صرفاً با ظاهرشدن صفحهٔ اصلی «سازگار» اعلام نمی‌شود؛ مسیر جست‌وجو تا تصویر فصل باید آزمایش شود.
- حداقل وابستگی و استفاده از کتابخانه‌ها و ابزارهای مشترک موجود در upstream.
- ساخت تکرارپذیر، بررسی lint و آزمون‌های parser در CI.

## هشدار و سلب مسئولیت

MangOn وابسته یا مورد تأیید Mihon، Keiyoushi یا وب‌سایت‌های معرفی‌شده نیست. نصب افزونه‌های شخص ثالث می‌تواند به برنامه دسترسی گسترده بدهد؛ فقط افزونه‌های این مخزن و نسخه‌های منتشرشده از مسیر رسمی پروژه را نصب کنید. وضعیت دسترسی و شرایط استفادهٔ هر منبع ممکن است تغییر کند.

## مشارکت

گزارش خرابی منبع، تغییر دامنه، خطای فصل یا پیشنهاد بهبود را با ذکر URL عمومی و بدون ارسال اطلاعات ورود/حساب ثبت کنید.
