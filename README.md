# MangOn — افزونه‌های فارسی Mihon

MangOn مجموعه‌ای مستقل برای ساخت و انتشار افزونه‌های فارسی سازگار با **Mihon** است. ماژول‌ها از قرارداد جاری Keiyoushi استفاده می‌کنند و برای build، toolchain بالادستی را در CI دریافت می‌کنند؛ کد منبع MangOn در همین مخزن نگهداری می‌شود.

> **وضعیت:** نخستین ماژول ManhwaChi پیاده‌سازی اولیه شده است. تا زمانی که GitHub Actions ساخت و lint را با موفقیت تمام نکند و APK در Mihon آزمایش نشود، آن را انتشار پایدار یا کاملاً سازگار تلقی نکنید.

## دریافت خروجی آزمایشی

پس از اجرای موفق workflow با نام **Build MangOn extensions**:
1. به بخش Actions همین مخزن بروید.
2. اجرای موفق را باز کنید.
3. از بخش Artifacts فایل `mangon-manhwachi-apk` را دریافت کنید.
4. APK را فقط در محیط آزمایشی نصب کنید.

فعلاً مخزن افزونهٔ استاندارد Mihon و فایل `index.pb` منتشر نشده است؛ افزودن URL این مخزن به Mihon هنوز امکان‌پذیر نیست.

### محدودیت‌های شناخته‌شده ManhwaChi
- کاتالوگ عمومی فعلاً از صفحهٔ کتابخانه و حداکثر ۳۰ نتیجهٔ جست‌وجوی ارائه‌شده در صفحهٔ جست‌وجوی سایت خوانده می‌شود.
- صفحه‌بندی کاتالوگ هنوز پیاده‌سازی نشده است؛ صفحه‌های بعدی عمداً خالی گزارش می‌شوند.
- فصل‌هایی که سایت با نشان قفل یا شمارش معکوس مشخص می‌کند از فهرست حذف می‌شوند.
- صفحه‌خوان فقط URL تصاویر موجود در HTML عمومی فصل را می‌خواند؛ اگر فصل قفل باشد یا تصویر عمومی ارائه نشود، خطای روشن برمی‌گرداند.
- URL تصویرها امضاشده و زمان‌دار هستند؛ افزونه آن‌ها را فقط هنگام بازکردن فصل واکشی می‌کند و در دادهٔ دائمی ذخیره نمی‌کند.

## اصول
- فقط محتوای عمومی؛ بدون دورزدن ورود، اشتراک، پرداخت، محدودیت جغرافیایی یا کنترل ضدربات.
- هر منبع مستقل، با خطاهای قابل‌فهم و selectorهای مبتنی بر HTML واقعی.
- بدون backend یا پایگاه دادهٔ اضافی تا زمانی که نیاز واقعی وجود نداشته باشد.
- نسخهٔ انتشار فقط پس از build و آزمون واقعی افزایش می‌یابد.

MangOn مستقل است و وابستگی یا تأیید رسمی از Mihon، Keiyoushi یا وب‌سایت‌های منابع ندارد.
