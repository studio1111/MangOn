# MangOn — افزونه‌های فارسی Mihon

MangOn مجموعه‌ای مستقل برای ساخت و انتشار افزونه‌های فارسی سازگار با **Mihon** است. ساختار ماژول‌ها از قرارداد جاری Keiyoushi پیروی می‌کند و CI برای build از toolchain بالادستی استفاده می‌کند؛ کد منبع افزونه‌ها در همین مخزن نگهداری می‌شود.

> **وضعیت فنی:** ماژول ManhwaChi اکنون در GitHub Actions با موفقیت build و lint شده و APK آزمایشی تولید شده است. این نتیجه، آزمون نصب و اجرای واقعی در Mihon را جایگزین نمی‌کند؛ تا آن آزمون انجام نشود، افزونه stable اعلام نمی‌شود.

## دریافت APK آزمایشی

1. وارد بخش Actions مخزن شوید و اجرای موفق **Build MangOn extensions** را باز کنید.
2. از بخش Artifacts فایل `mangon-manhwachi-apk` را دریافت کنید.
3. فایل را در Mihon به‌صورت آزمایشی نصب و جریان‌های فهرست، جست‌وجو، جزئیات، فصل‌ها و صفحات را بررسی کنید.

Artifact فعلی از اجرای CI شمارهٔ 7 است و تا **2026-11-18 14:44 UTC** نگهداری می‌شود. اجرای جدید، artifact جدیدی تولید خواهد کرد.

فعلاً مخزن افزونهٔ استاندارد Mihon و `index.pb` منتشر نشده است؛ بنابراین URL نصب مخزن هنوز آماده نیست.

## محدودیت‌های شناخته‌شده ManhwaChi

- کاتالوگ عمومی فعلاً از صفحهٔ کتابخانه و حداکثر ۳۰ نتیجهٔ صفحهٔ جست‌وجوی سایت خوانده می‌شود.
- صفحه‌بندی کاتالوگ هنوز پیاده‌سازی نشده است؛ صفحه‌های بعدی عمداً خالی گزارش می‌شوند.
- فصل‌های دارای پرچم `data-free="0"`، نشان قفل یا برچسب اشتراک از فهرست حذف می‌شوند؛ افزونه paywall یا محدودیت دسترسی را دور نمی‌زند.
- صفحه‌خوان فقط تصاویر موجود در HTML عمومی فصل را می‌خواند و در نبود تصویر، خطای روشن برمی‌گرداند.
- URL تصویرها امضاشده و زمان‌دار هستند؛ باید هنگام واکشی فصل استفاده شوند و برای cache دائمی مناسب نیستند.
- search endpoint پارامتری و صفحه‌بندی پایدار از سوی سایت تأیید نشده است.

## توسعه

- ساخت و lint با GitHub Actions و toolchain جاری Keiyoushi انجام می‌شود.
- هر تغییر در `src/**` به‌صورت خودکار build و lint می‌شود.
- قبل از افزودن منبع جدید، مسیر عمومی reader و تصاویر آن باید با شواهد زنده تأیید شود.
- فقط محتوای عمومی و مجاز پشتیبانی می‌شود؛ دسترسی اشتراکی، قفل، geo-restriction یا anti-bot دور زده نمی‌شود.
