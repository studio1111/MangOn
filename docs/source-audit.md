## ManhwaChi — مسیرهای تأییدشده

- کتابخانه: `/library-page.html`؛ کارت‌ها در `#manhwaGrid .manhwa-card` با `data-link`، تصویر و عنوان قرار دارند.
- جست‌وجو: `/search.html`؛ DOM عمومی در زمان بررسی ۳۰ عنوان ثابت را در `#top a.card` نشان می‌دهد. رابط جست‌وجو روی داده‌های همین صفحه کار می‌کند؛ پارامتر GET برای query تأیید نشده است.
- جزئیات: `/comic/{slug}`؛ عنوان فارسی `#faSubtitle`، عنوان اصلی `#manhwaTitle`، جلد `#dynamic-cover`، توضیح `#dynamic-description` و ژانرها `#type a`.
- فصل‌ها: `#episodeList a.episode-card`. نمونهٔ زنده شامل `data-free="1"` و badge با کلاس `.mx-st.free` بود. پیاده‌سازی علاوه بر `data-free="0"`، نشان‌های قفل و برچسب‌های فارسی اشتراک/ویژه را نیز رد می‌کند.
- خواننده: `/reader.html?slug=...&ch=...`; صفحات عمومی در `#reader .manhwa-panel img[src]` ارائه می‌شوند.
- در نمونهٔ فصل ۳۹ از «سرزمین فراموش‌شده»، ۹ تصویر در HTML reader مشاهده شد. آدرس تصاویر دارای `token` و `expires` است؛ URLها موقت‌اند و نباید cache دائمی شوند.

## وضعیت build

- GitHub Actions run شمارهٔ 7 با شناسهٔ `41850178992` در commit `352fd35169de4c60f45394a31bf58da7eba42405` موفق شد.
- هر دو مرحلهٔ `assembleRelease` و `lintRelease` در مرحلهٔ Build and lint موفق بودند.
- Artifact با نام `mangon-manhwachi-apk` تولید شد؛ اندازهٔ archive برابر 35,135 bytes است و تا 14 روز پس از ساخت نگهداری می‌شود.
- این CI ساخت و lint را ثابت می‌کند، نه نصب، اتصال شبکه و عملکرد در Mihon واقعی.

## محدودیت‌ها و کارهای باز

1. صفحه‌بندی کتابخانه در UI دیده می‌شود، اما endpoint/پارامتر پایدار صفحهٔ بعد هنوز تأیید نشده؛ افزونه صفحه‌بندی ساختگی ارائه نمی‌کند.
2. جست‌وجوی سایت client-side است و endpoint پارامتری تأیید نشده است.
3. باید APK روی Mihon نصب و browse/search/details/chapters/pages دستی آزمایش شود.
4. پیش از افزودن هر منبع دیگر، URL فصل رایگان و HTML تصاویر آن باید مستقیماً بررسی شود.
5. فقط محتوای عمومی و مجاز؛ قفل اشتراک، paywall، محدودیت جغرافیایی و anti-bot دور زده نمی‌شوند.
