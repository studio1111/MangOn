## ManhwaChi — مسیرهای تأییدشده

- کتابخانه: `/library-page.html`؛ کارت‌ها در `#manhwaGrid .manhwa-card` با `data-link`، تصویر `.card-cover` و عنوان `.manhwa-title`.
- جست‌وجو: `/search.html`؛ DOM عمومی در زمان بررسی ۳۰ عنوان ثابت را در `#top a.card` نمایش می‌داد. ورودی جست‌وجو در رابط صفحه با JavaScript روی همین فهرست کار می‌کند؛ پارامتر GET جست‌وجو تأیید نشده است. افزونه فعلاً query را روی همان ۳۰ عنوان فیلتر می‌کند.
- جزئیات: `/comic/{slug}`؛ عنوان فارسی `#faSubtitle`، عنوان اصلی `#manhwaTitle`، جلد `#dynamic-cover`، توضیح `#dynamic-description`، ژانر `#type a`.
- فصل‌ها: `#episodeList a.episode-card`; فصل قفل‌شده با `.mx-lock` و/یا `.lock-pill` مشخص می‌شود.
- خواننده: `/reader.html?slug=...&ch=...`; صفحات آزاد در `#reader .manhwa-panel img[src]` ارائه می‌شوند. URL تصویرها دارای token و expires هستند و باید در لحظهٔ واکشی استفاده شوند.

## آزمون دسترسی فصل

در نمونهٔ بررسی‌شده، فصل ۳۹ تصاویر عمومی در HTML reader داشت. فصل ۴۰ در همان زمان به‌علت قفل زمانی/اشتراک صفحهٔ قفل را نمایش داد و تصاویر فصل را ارائه نکرد. افزونه هیچ تلاش برای عبور از قفل انجام نمی‌دهد.

## محدودیت‌ها و کارهای باز

1. کاتالوگ صفحه‌بندی دارد، اما دکمه‌های صفحه در HTML به‌صورت button هستند و endpoint/پارامتر پایدار صفحهٔ بعد هنوز تأیید نشده؛ افزونه صفحه‌بندی جعلی ایجاد نمی‌کند.
2. جست‌وجوی وب‌سایت client-side روی دادهٔ موجود در صفحه است؛ query پارامتری GET تأیید نشده است.
3. باید selectorها با fixture و build واقعی upstream اعتبارسنجی شوند.
4. باید APK روی Mihon نصب و جریان browse/search/details/chapters/pages به‌صورت دستی آزمایش شود.
5. فقط محتوای عمومی و مجاز؛ قفل اشتراک، paywall، محدودیت جغرافیایی و anti-bot دور زده نمی‌شوند.
